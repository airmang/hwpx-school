# 새 학교 등록 — 빈 원안지 서식 → 학교 킷·학교 스킬

**결과물은 사용자 로컬이다.** 등록으로 생기는 학교 킷 폴더(kit.json·rules.json·habits.json·README·결정표·SKILL.md)와 서식 원본·해부 보고는 제품 저장소에 넣지 않는다 — 사용자가 정한 로컬 킷 폴더 아래 `<학교>-원안지/`에 둔다.

## 0. 받는 것

- 그 학교의 **빈** 원안지 서식(제출본이 아님). `.hwp`면 python-hwpx 6.6.0 이상으로 hwpx로 바꾼다(`HwpxDocument.open("x.hwp")` → 저장, `conversion_report` 확인). 변환본은 원본과 함께 미추적 위치에 둔다.
- 변환본을 실한컴으로 한 번 렌더해 원본 .hwp 렌더와 픽셀 대조한다(실례: 차이 0). 이 렌더가 해부의 눈이다 — 색 글자·화살표·메모 풍선이 보인다.
- 있으면 그 학교 문항 제작 연수자료(학교 규칙)와 제출본(교사 습관 실측). 없으면 규칙은 서식 속 안내·메모에서, 습관은 엔진 기본(첫 등록 학교 실측)에서.

## ① 해부 (기계)

    uv run python -m exam_kit.onboard scan "<서식.hwpx>" --out <미추적>/해부.md

용지·단, 스타일(글자 모양·줄간격·여백·탭·자동번호·본문 사용 수), 누름틀, 메모, 그리기 개체, 머리말·꼬리말, 최상위 문단(색 글자·표·나눔), 표(모양·크기·글자처럼·안 문단 스타일), 구조 후보(번호 방식·꼬리 박스·지울 구역 시작).

## ② 제안 (스킬) → ③ 결정표 (사용자)

해부 보고와 렌더를 읽고 항목마다 **서식에서 본 것 · 제안 · 구분(A = 서식이 스스로 말함, B = 사용자 판단)**을 적는다. 틀리면 학교 서식을 지우게 되므로 방향 승인이 아니라 항목별로 확정받는다. 실례(글자 자리 양식 한 학교)는 35항목(A 28 · B 7)이었다.

| 묶음 | 항목 |
|---|---|
| 용지·글자 | 용지·단, 본문 글자(서식 안내 글과 대조), 번호 방식(자동번호 스타일 / 글자 번호의 글자 모양), 배점 표기, 세트 머리, 발문 둘째 줄 |
| 스타일 역할 | number · choice1/2/3/5 · box_guide(〈보기〉 안) · box(자료 안) · normal — **견본 표 안 문단의 실제 스타일**로 정한다(이름이 그럴듯해도 견본이 안 쓰면 아니다) |
| 머리 값 | 누름틀이면 id ↔ 뜻, 없으면 글자 자리(칸·유의 상자·꼬리말의 찾을 글 → 채울 틀). 출제교사 여러 명·편집자 차례, 총쪽수 |
| 지울 것 | 메모, 색 안내 글(관리박스 문단에 붙은 것 포함), 그리기 개체, 샘플 문항 구역, 논술형 샘플, 복사용 견본, 지울 구역 시작 규칙(첫 쪽 나눔 / 글 머리) |
| 박스·꼬리 | 〈보기〉·〈조건〉·자료 견본(모양·제목·내용 칸·레일·떠 있는 표인지), 꼬리 박스 식별어·자리 |
| 학교 규칙 | 연수자료 [기계] 규칙 또는 서식 메모 규칙 → `rules.json` 코드별 |

## ④ 킷

    uv run python -m exam_kit.onboard draft "<서식.hwpx>" --name <학교>-원안지 --out <로컬 킷 폴더>/<학교>-원안지

사실(sha·용지·여백·단 폭·꼬리 가로 자리)만 채워지고 판단 항목은 `TODO`다 — 결정표대로 채운다. 값의 모양은 `exam/README.md`와 엔진 `exam_kit/kit.py`(키 목록·주석)가 정본이고, 저장소의 **합성 킷 `exam/kits/synthetic`**(학교 무관 합성 서식과 짝 — 글자 자리 슬롯·글자 번호·텍스트 층 판정)이 완전한 예다. `load_kit`은 TODO·빠진 키·모르는 키에서 멈춘다.

글자 폭(`metrics`)과 렌더 판정(`render`)은 실한컴으로 잰다:
- 본문이 PDF에서 **텍스트 층**으로 나가면(예: 휴먼명조) `render.glyphs = "text"`, `text_fonts` = 본문·박스 글꼴의 PDF 이름. 곡선으로 나가면(예: 한양신명조) `"curves"`.
- 텍스트 층이면 합성 원고(대소문자·숫자·문장부호·한글 줄)를 조판·렌더해 같은 줄 이웃 글자 기준점 간격을 잰다 → 전각·공백은 중앙값, 반각·대문자는 넉넉히(큰 쪽).

## ⑤ 확인 (기계)

- 서식 준비 테스트: 메모·그리기 0, 지울 구역 사라짐, 꼬리 박스가 마지막 문단·용지 기준 고정, 견본 채집(`exam/tests/test_text_slot_form.py`가 틀 — 킷·서식은 환경변수로).
- 합성 원고(그 학교 박스 종류를 다 쓰는 것)를 `build`로 조판 → 두 판 기계 잔존 0.
- **기존 학교 회귀**(엔진을 고쳤다면).

## ⑥ 사용자 검수

G1(서식 준비·머리 값) · G2(유형별 합성 견본) — 원본 서식 렌더와 조판 결과를 나란히, 절대 경로와 `open` 명령으로. 판정은 말 그대로 결정표에 적는다. 합격하면 학교 스킬 `<로컬 킷 폴더>/<학교>-원안지/SKILL.md`(서식 위치·sha·킷·그 학교만의 주의)를 만든다.
